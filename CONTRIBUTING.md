# Contributing

`main` is protected. Nobody pushes directly to it — changes land through a pull request.

## Workflow

1. Create your own branch off `main`:
   ```
   git checkout -b feature/short-description
   ```
   (or `bugfix/short-description` for a fix)
2. Commit your changes there and push the branch:
   ```
   git push -u origin feature/short-description
   ```
3. Open a Pull Request into `main`.
4. Wait for review and approval from the repository admin before it's merged. Do not merge your own PR.

This applies to anyone working on this project other than the repository admin.
