# ProjectFlow – Full-Stack Project Management Platform

**Technologies:** C#, .NET 10, ASP.NET Core Web API, React, TypeScript, PostgreSQL, Entity Framework Core, Docker.

Designed and developed a full-stack project management platform that enables teams to organize workspaces, manage projects, assign tasks and track productivity.

- Developed RESTful APIs using ASP.NET Core and Entity Framework Core.
- Implemented authentication and role-based authorization.
- Designed relational database structures using PostgreSQL.
- Built a responsive frontend using React and TypeScript.
- Implemented task management, Kanban boards and real-time notifications.
- Created automated unit and integration tests.
- Configured Docker and CI/CD workflows using GitHub Actions.
